# 最小核心链路

## 链路

```text
样例 Vault → RunManager → collect StageIO → LLM Replay 抽取
→ extract StageIO → SQLite 持久化 → Run 收尾
```

## 交付内容

- Pipeline 首次运行可创建并收尾 Run。
- collect / extract 阶段状态和中间产物可查询。
- 抽取结果写入 `extractions` / `events`。
- Replay 模式不联网、不产生真实调用成本。
- 失败条目进入失败清单，不阻塞其他成功条目。
