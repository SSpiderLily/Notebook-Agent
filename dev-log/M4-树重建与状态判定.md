# M4 树重建与状态判定

## 交付内容

- 基于 LangGraph 的真实多轮 ReAct 树重建 Agent。
- 五个白名单工具：候选树检索、回读笔记、树时间线、事件检索、终态提交。
- Agent 每事件最多 12 步，并统一通过 LLMGateway。
- 新增 `TreeAssignment`、`DraftTree`、`DraftForest` 草稿森林模型。
- 新增 `trees` / `tree_nodes` 持久化表。
- verified 树只允许追加叶子；非法移动、拆分、重组进入人工复核队列。
- 树状态判定支持：
  - `complete`
  - `in_progress`
  - `dangling_confirmed`
  - `dangling_suspected`
- 断头树清单和状态证据写入 StageIO。
- Pipeline 接入 `tree_rebuild` 与 `status_judge` 阶段。

## 验证结果

覆盖 ORM、ReAct 工具循环、追加原则、状态判定和断头检测；M4 完成时全量测试 101 项通过。
