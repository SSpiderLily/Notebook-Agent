# 如何学习Python

Python是一门易于学习且功能强大的编程语言。

## 基础语法

Python的基本语法包括：

```python
def hello(name):
    print(f"Hello, {name}!")

hello("World")
```

## 学习路径

1. **基础语法** - 变量、数据类型、控制流
2. **函数** - 定义和调用函数
3. **面向对象** - 类和对象
4. **标准库** - 常用模块
5. **项目实践** - 实际项目开发
